# STARLOOM — Weave Light. Bind the Void.

An arcade **loop-drawing game** that runs entirely in the browser. Single file, no dependencies, no build step.

## Run
Open `index.html` in any modern browser (works on mobile too). Or host it on Netlify / GitHub Pages as-is.

## What's inside
- Draw loops of light to trap and bind enemies in the void
- In-game tutorial ("How to play"), Settings, Trophies, pause and progress reset
- Responsive, touch-friendly, dark space theme built with CSS design tokens

## Tech
Vanilla HTML + CSS + JavaScript (canvas). Everything is in one `index.html`.
